# Holbegram

## Description

This repository contains the Holbegram project, a mobile social media application inspired by Instagram, developed with Flutter as part of the Holberton School curriculum.

The objective of this repository is to group all resources, code, and documentation related to the Holbegram project, following Holberton School standards for project organization and documentation.
